A production-grade car rental and marketplace platform where users can rent cars, buy cars, manage bookings, orders, favorites, reviews, and communicate through real-time chat.

The platform includes separate flows for users, traders, and admins, with scalable frontend architecture and API-driven features.

**Key Features:**

* 🚗 Car rental and car buying flows
* 🧑‍💼 Trader dashboard for managing rental and sale cars
* 📦 Booking and order management
* ❤️ Wishlist and saved cars
* ⭐ Reviews and ratings
* 💬 Real-time chat and notifications
* 🔐 Authentication and protected routes
* 🌍 Multi-language support with RTL/LTR layouts
* 📱 Fully responsive UI

**Tech Stack:**
Next.js, React, TypeScript, Tailwind CSS, Redux Toolkit, Zustand, React Query, REST APIs, Socket.io, Express.js, MongoDB
